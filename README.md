# Age Calculator

## Project Overview
Age Calculator is a mini project developed using C Programming Language.
It calculates a person's age in Years, Months and Days based on the Date of Birth.

## Objectives
- To calculate accurate age.
- To understand C programming concepts.
- To validate the Date of Birth.
- To handle leap years.

## Features
- Takes Date of Birth as input.
- Uses the current system date.
- Calculates age in Years, Months and Days.
- Checks invalid dates.
- Prevents future Date of Birth.
- Supports leap year calculation.

## Technologies Used
- Programming Language: C
- Compiler: OnlineGDB
- Header Files: stdio.h, time.h

## How to Run
1. Open the main.c file.
2. Compile and Run the program.
3. Enter Date of Birth in DD MM YYYY format.
4. View the calculated age.

## Example Input
15 08 2000

## Output
Displays age in Years, Months and Days.
